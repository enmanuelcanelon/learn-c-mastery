# Learn C from Scratch to Mastery

A complete, friendly, and professional interactive guide to learning the **C programming language** — from absolute beginners to advanced mastery.

## 🎯 Who is this for?

- Complete beginners who have never written a line of code
- Developers coming from higher-level languages who want solid foundations
- Students preparing for systems programming, embedded, OS, or performance-critical work
- Anyone who wants to truly *understand* how computers work under the hood

## 🧑‍🏫 Teaching Style

Friendly • Easy to understand • Professional • Excellent teacher approach

Clear explanations, practical examples, progressive difficulty, and real-world context.

## 📚 Curriculum Overview

### Phase 1 — Foundations (Beginner)
- Setting up your environment
- Your first program
- Variables, types, and operators
- Control flow (if, loops)
- Functions

### Phase 2 — Core Concepts (Intermediate)
- Arrays and strings
- Pointers (the heart of C)
- Memory management
- Structures and unions
- File I/O

### Phase 3 — Advanced (Advanced)
- Dynamic memory
- Linked lists and data structures
- Preprocessor and macros
- Multi-file projects
- Debugging and tools

### Phase 4 — Mastery
- Systems programming concepts
- Performance and optimization
- Common pitfalls and best practices
- Building real projects
